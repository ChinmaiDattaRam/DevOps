# DevOps Exercises

Each exercise has its own `Lab-N` directory with runnable source/configuration,
a README containing the code and commands, and captured results under
`screenshots/`.

| Lab | Exercise |
| --- | --- |
| [Lab-1](./Lab-1/README.md) | Kubernetes Nginx Pod |
| [Lab-2](./Lab-2/README.md) | Flask on Minikube |
| [Lab-3](./Lab-3/README.md) | Scale Flask with a ReplicaSet |
| [Lab-4](./Lab-4/README.md) | Docker bridge networking |
| [Lab-5](./Lab-5/README.md) | Docker AppArmor security |
| [Lab-6](./Lab-6/README.md) | Prometheus and Grafana delivery metrics |
| [Lab-7](./Lab-7/README.md) | Jenkins CI automation |
| [Lab-8](./Lab-8/README.md) | Jenkins Hello World job |
| [Lab-9](./Lab-9/README.md) | Jenkins multi-stage pipeline |
| [Lab-10](./Lab-10/README.md) | Multi-node Minikube applications |

Each lab README links to a sequence of JPGs documenting its setup, verification,
and final output. Browser captures show application pages; staged captures show
the command, API, or Jenkins output from the live reruns. Host-dependent steps
are called out in that lab's README.
